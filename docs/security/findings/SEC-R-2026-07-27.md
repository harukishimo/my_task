# SEC-R レッドチーム所見

## 対象

ローカルProductionビルド、認証API、タスクAPI、生成HTML、依存監査。Production環境や実秘密情報は対象外。

## 検証結果

- 未認証のタスクAPIは401を返す。
- 未認証のルートはログイン画面へリダイレクトされる。
- ログイン成功時のCookieはHttpOnly、SameSite=Lax、ProductionではSecure、90日有効期限。
- 更新APIはOrigin／Sec-Fetch-Siteを検査する。
- `priority`は入力値ではなく緊急度・重要度から再計算する。
- version不一致は409を返す。
- API応答はno-storeで、エラー本文へ秘密情報を含めない。
- Google秘密情報はserver-onlyコードに閉じている。
- Production依存の`npm audit --omit=dev`は0件。

## 未確認

- 実Google Sheets権限設定、Vercel Preview環境分離、ブラウザNetwork上の実環境値露出はOwner設定後にPreviewで再確認する。
