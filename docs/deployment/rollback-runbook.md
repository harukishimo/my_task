# 障害時の切り戻し手順

## アプリの切り戻し

1. Vercelで直前の正常なDeploymentを特定する。
2. そのDeploymentをProductionへ再デプロイする。
3. ログイン、一覧、追加、更新、ログアウトを確認する。
4. 原因修正は新しいPreviewで行う。

## データの復旧

コードの切り戻しではGoogle Sheetsの変更は戻りません。現在のシートを複製して調査用に保管し、バックアップのA〜L列とヘッダーを確認してから影響行だけを復旧します。

## 全セッション失効

第三者利用の疑いがある場合は、Productionの`SESSION_SECRET`を新しい値へ変更して再デプロイします。必要に応じて`APP_PASSPHRASE_HASH`も変更します。

## Google鍵交換

新しい鍵を作成してPreviewで接続確認し、Productionへ反映した後、古い鍵を無効化・削除します。鍵をGit履歴から削除する必要がある場合は、別途慎重な履歴対応を行ってください。
